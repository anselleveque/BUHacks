# Figma redesign: the "night" look (T41)

Source: the user's Figma prototype (https://www.figma.com/proto/4YNBGRqVA0712rOyUZrLPO/Untitled, a phone-width flow). Reference images captured from it are in `design/figma/` (attach and study ALL of them before coding; they are the source of truth, this document only describes them):
`01-plan-your-night.jpg`, `02-plan-open-late-list.jpg`, `03-your-night.jpg`, `04-your-night-timeline.jpg`, `05-pinned-night.jpg`, `06-missed-train.jpg`.
Each image shows the 390 px wide phone frame scaled to about 304 px (multiply sizes you measure by 1.28 to get CSS px). The prototype has no desktop frames and no map; see "Decisions" below.

## Goal
Restyle and re-lay-out the whole app to match this design: a calm, dark "night" interface with a lime accent, bigger type, quieter cards and one obvious primary action at the bottom of every screen. Keep every existing feature and behavior; this is a visual and layout change (plus the small new states listed below).

## Design tokens (approximate, sampled from the images; match by eye and compare screenshots side by side)
- Page background `#131b1a` (very dark teal-green charcoal), header the same with a 1 px bottom border `#2f3837`. Surface (cards, tiles, selects) `#1d2623` with a 1 px border `#232c2b`; inputs and select fields slightly darker `#0f1515` with border `#202928`; chip border `#2f3837`.
- Text: primary near-white `#f1f4ee`, secondary muted `#aab3ac`, tertiary `#7d877f`.
- Accent lime `#dfe9b1` (selected chips, primary button fill, slider fill and thumb, the large Total, the checked checkbox) with dark text `#1a221a` on it. Mint selected border `#8ed0a4` for the selected route chip and the current step card. Status green `#8fd3a8` for countdown numbers and the GO label; EAT label yellow `#e3d37a`; HOME label blue `#8db4e6`; urgent/coral `#ee8f86` for the missed-train banner, the "missed" chip and the pinned timer digits under 5 minutes.
- Type: a clean sans (Inter if available through the system stack, else system-ui). Screen title 28 px semibold ("Plan your night", "Your night"), card title 20 px, body 15 to 16 px, secondary 13 px, section labels in small caps style 13 px letter-spaced ("01 GO"). Radius 12 px for cards, 10 px for chips and selects, 999 px for the segmented control and pills. 8 px spacing grid, 16 px screen gutters, 48 px minimum touch height for chips, selects and buttons; the primary button is 56 px tall, full width minus gutters, lime fill, semibold 16 px text.
- Focus rings stay visible (lime 2 px outline offset 2 px); respect `prefers-reduced-motion`; text contrast must stay at least WCAG AA on the dark surfaces.

## Chrome
- Header (about 64 px): left a moon icon plus the wordmark "Midnight Munch" (semibold 18 px); right two square 44 px bordered icon buttons: a moon icon (theme toggle) and a person icon (profile; opens the existing profile screen; it also shows the level and points on wider screens). The existing stamp and points chip moves into the profile screen on phone width.
- Theme: dark is the DEFAULT. The moon button toggles to a light theme built from the same tokens inverted (use the app's current light palette as the base: off-white `#f7f8f2`, green `#224b3b`, lime `#d9ed9b`), saved in localStorage (`midnight-munch-theme`), and it must also set `color-scheme` and the map tiles to match. Respect `prefers-color-scheme` only for the first visit if no choice was saved is NOT wanted: first visit is always dark.
- Sticky bottom action bar on phone: a 56 px lime primary button pinned to the bottom with a top border and safe-area padding (`env(safe-area-inset-bottom)`); content scrolls under it with matching bottom padding (so nothing, including the "Browse places" button, is ever hidden behind it).

## Decisions where the prototype is silent (follow these)
- Map: the prototype shows none. Keep the map. On phone widths show it in a full-screen layer opened by a "Map" pill button in the header area (a second row under the header, right aligned, next to the segmented control row is acceptable) with a "Back to plan" pill; route lines, pins and the legend keep working. On desktop (900 px and up) keep two columns: the phone-style panel (440 px wide, same design) on the left and the map filling the rest, with dark map tiles in the dark theme (MapTiler's dark style when the key is configured, else invert and dim the OSM tiles with a CSS filter) and the normal tiles in the light theme.
- Browse, profile, dialogs, the combobox list, chips, banners and every other screen not in the prototype are restyled with the same tokens and components, not redesigned.
- Wide screens: the panel stays 440 px wide and the page background is the same dark color; no stretched layouts.

## Acceptance
- Phone (375x812 and 390x844) screenshots of each of the five states look like the six reference images at the same scale (check type sizes, spacing, radii, colors, the sticky button) when run against the mock with the same data (use the demo clock `?now=2026-11-21T21:12:00` and the dish and times in the images where the mock allows; otherwise equivalent).
- Dark is the default and the toggle switches themes and map tiles and persists.
- All earlier features still work and tests pass (pinned trips, ride options, estimates, stale-plan handling, closed places, profile screen, filters, favorites, station search, markers, no straight lines).
- No text is cut off or hidden behind the sticky button at 320, 375, 390 and 430 px widths, with the on-screen keyboard open and with large text (browser zoom 200 percent).
- Keyboard and screen reader behavior unchanged or better (labels for the icon buttons: "Switch to light theme", "Profile").
